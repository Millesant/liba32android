# ARM ELF32 R_ARM_REL32 evidence — 2026-09-25

Source: Arm ABI repository, `ARM-software/abi-aa/aaelf32/aaelf32.rst` (main branch), consulted 2026-09-25.

The specification assigns code 3 to `R_ARM_REL32` and defines the data-relocation operation as `((S + A) | T) - P`. For `STT_FUNC`, the stored symbol value uses bit zero to distinguish Thumb code, but relocation `S` uses the instruction address with that discriminator removed. `T` is one only when the target symbol is an `STT_FUNC` addressing Thumb code.

Feature 012 uses those rules only for the existing main `Elf32_Rel` path. It does not infer instruction relocation encodings or broaden the accepted symbol/visibility/versioning contract.
